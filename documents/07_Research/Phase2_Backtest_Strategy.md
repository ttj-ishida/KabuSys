### 2.3 Sharpe 頭打ちの構造的原因

Group A〜Q（延べ 100+ シナリオ）の検証を通じて判明した根本原因:

**「max_positions=3 + util=30% という高集中構成が、2018・2024 年の高ボラ局面に収益を偏中させている」**

```
年次リターン分布（P2_n1b_o2）:
  2017: -6.5%    2018: +64.3%   2019: +0.8%
  2020: +4.2%    2021: -3.4%    2022: -2.2%
  2023: -0.8%    2024: +27.7%   2025: +2.1%
  → 2018・2024 の 2 年で CAGR の大半を生成
  → 残る 7 年がフラット〜マイナス → 年次標準偏差が大きく Sharpe が低い
```

## 5.7 分析結果・採択判断（2026-05-31）

### 5.7.1 OOS_full が IS を概ね再現 — 実装・データに問題なし

OOS_full（7.92%、Sharpe 0.413）と IS 参照（8.31%、Sharpe 0.428）の乖離は微小（CAGR −0.39pt、Sharpe −0.015）。スクリプトとパラメータに問題はなく、9 年通算では過剰適合リスクは低い。

### 5.7.2 NG の構造的原因 1 — 2018 年への収益一極集中

2018 年の +63% が 9 年 CAGR 7.92% を支えており、OOS 期間（2022〜2025）には同様の急伸がなかった。

```
OOS期間（2022〜2025）の年次平均 ≈ 0.81%/年
2018年を除いた残り8年の年次平均 ≈ +1.4%/年
→ Phase 1 から一貫して指摘されていた収益集中構造が OOS で顕在化
```

**これは #375 Group R（ポジション数拡大による分散）が解決しようとしている問題そのもの。**

### 5.7.3 NG の構造的原因 2 — 2024 年 −4.25%（施策 B の影響疑い）

Phase 1 文書 Section 28b で I1（施策 A+B なし）の 2024 年は +27.65% だった。P2_n1b_o2 では −4.25% と大幅に異なる。

```
I1（施策 A+B なし）: 2024年 +27.65%
P2_n1b_o2（施策 A+B あり）: 2024年 −4.25%
差分: −31.9pt
```

施策 B（多段階トレーリングストップ）が 8 月急落後の急速な回復局面でポジションを早期に刈り取った可能性が高い。Group O の検証（施策 B 単体は I1 を下回る）と整合する。

### 5.7.4 リスク管理は機能している

OOS 期間（2022〜2025）の MaxDD 14.23% は基準（25%）を大きく下回る。DD Stop と MA200 フィルターはリスク抑制として有効に機能している。

## 6. Section 48 — Group R: ポジション数・utilization グリッドサーチ（Issue #375）

### 6.1 背景・仮説

Phase 1 の Sharpe 頭打ち（0.428）は **max_positions=3 + util=30% という高集中構成** に起因する。
Phase 2（資本 〜500万円）でポジション数を拡大することで銘柄分散が増し、
年次リターンのブレ（Sharpe の分母）を抑制できる。

Phase 1 の検証知見:
- Group G3（util=30%）→ Group I1（util=30% + MA200）: utilization 変更が MaxDD 改善の主要因
- Phase 1 では 1 銘柄あたり最大 10%（30% / 3 銘柄）を占める集中度

**この検証は追加実装ゼロ。パラメータ変更のみで実行できる。**

### 6.2 シナリオ定義

ベース設定: P2_n1b_o2（施策A+B ON、MA200 ON、BG OFF、DD stop=12%）  
固定設定: threshold=0.58, stop_loss=9%, 施策A ON, 施策B ON, 期間 2017〜2025

| シナリオ | max_positions | max_utilization | 1銘柄リスク比率 | 狙い |
| -------- | ------------- | --------------- | --------------- | ---- |
| R0_p2_ref | 3 | 30% | 10.0% | P2 参照（Phase 1 最終採用） |
| R1 | 5 | 40% | 8.0% | 銘柄数+2・投下率+10pt |
| R2 | 5 | 50% | 10.0% | 銘柄数+2・投下率+20pt |
| R3 | 7 | 40% | 5.7% | 銘柄数+4・投下率+10pt（分散重視） |
| R4 | 7 | 50% | 7.1% | 銘柄数+4・投下率+20pt |
| R5 | 7 | 60% | 8.6% | 銘柄数+4・投下率+30pt（積極） |
| R6 | 10 | 50% | 5.0% | 最大分散（Phase 2 上限候補） |

> **1銘柄リスク比率** = max_utilization / max_positions。R3（5.7%）が Phase 1（10.0%）の約半分。

**読み方**:
- R0 → R1〜R6: ポジション数と投下率の組み合わせが Sharpe・CAGR・MaxDD をどう動かすか
- `max_positions × (1銘柄あたりサイズ)` の総量が MaxDD と CAGR の両方を規定する

### 6.3 採択判断ロジック

```
いずれかのシナリオで Sharpe > 0.5 かつ CAGR > 8% かつ MaxDD < 25%
  → 当該設定を Phase 2 採用候補として選択 → Section 49 のベースとする

全シナリオで Sharpe > 0.5 未達だが R0（P2）より Sharpe が改善
  → 最良設定を Phase 2 ベースとして採用、Sharpe 改善は Group S に委ねる

全シナリオで R0 以下
  → ポジション数拡大では構造改善不可。Phase 3 課題として保留
```

## 6.6 分析結果・採択判断（2026-06-01）

### 6.6.1 発見 1: util=40% が最適ライン

util を 40% に抑えると Sharpe が改善し MaxDD の増加も限定的。50% 以上に引き上げると Sharpe が急落し MaxDD が爆発的に増加する。

```
util=40% 固定でポジション数変化:
  R1（5銘柄, 8.0%/銘柄）: Sharpe 0.436、MaxDD 32.52%
  R3（7銘柄, 5.7%/銘柄）: Sharpe 0.445、MaxDD 26.87%
  → 銘柄分散の効果あり（Sharpe +0.009、MaxDD -5.65pt）
```

### 6.6.2 発見 2: R3 が全指標で R0 を上回る（最有望設定）

R3（pos=7, util=40%, 1銘柄配分5.7%）は R0 比で CAGR +1.09pt・Sharpe +0.032・PF +0.112 と全面改善。MaxDD は 22.45% → 26.87% へ +4.42pt 悪化し基準（25%）を 1.87pt 超過。

### 6.6.3 発見 3: R6（10銘柄）は CAGR 最高だが MaxDD が許容外

R6（pos=10, util=50%）は CAGR 9.75% と最高だが MaxDD 39.10%。分散効果より投下率増加による MaxDD 拡大が支配的。

### 6.6.4 Sharpe 0.5 未達の理由

Group R は「収益の 2018 年集中」を一部緩和したが、CAGR の年次偏中構造は依然として残る。
Sharpe = CAGR / 年次リターン標準偏差 の分母の改善には Group S（マルチレジーム閾値）が必要。

```
R0 → R3 の年次リターン標準偏差: 24.76% → 26.22%（+1.46pt）
→ ポジション拡大が取引回数とボラを増やし分母を押し上げた
```

### 6.6.5 採択判断

```
採択基準（Sharpe > 0.5 かつ 3 指標）: 全シナリオ未達
Sharpe が R0 を上回るシナリオが存在: R1（0.436）、R3（0.445）、R6（0.433）
→ R3 を Phase 2 ベース設定として採用候補に昇格
→ Sharpe 0.5 突破は Section 49 Group S（マルチレジーム閾値）に委ねる
→ R3 の MaxDD 26.87%（基準 25% まで 1.87pt）は Group S のパラメータ調整で改善を狙う
```

### 8.7.1 発見 1: T4/T5/T6 の MaxDD は 2020-10-01 TSE システム障害に起因するデータアーティファクト

2020-10-01 は **東証がシステム障害で終日取引停止**した日。同日の価格データが DB に存在しない銘柄についてバックテストエンジンがポジション価値 0 と評価し、`portfolio_value = cash のみ` と記録された結果、擬似的に 95% ドローダウンが発生している。

## 10. Section 52 — Group V: エグジットロジック改善（Issue #384, #385, #386）

### 10.1 背景・分析

Group U（U1_t4）の全 841 トレードを保有期間別に分析した結果、以下の構造が判明した：

```
保有期間別パフォーマンス（U1_t4 / 2017-2025）:

  0〜7日  : 127件（15%）  勝率  4.7%  平均 −9.1%  ← ほぼ全件ストップロス
  8〜14日 : 548件（65%）  勝率 46.4%  平均 +1.2%  ← スコア低下離脱（score_drop）
  15〜30日:  94件（11%）  勝率 69.1%  平均+12.9%  ← 正常なトレンド保有
  31〜60日:  37件（4%）   勝率 64.9%  平均+34.9%  ← 大型勝者
  61日超  :  31件（4%）   勝率 25.8%  平均+42.9%  ← 時間切れ（保有しすぎ）
```

**負けは買った時点で決まっているか？**
- 0-7日（ストップ）: **概ね YES** — エントリー直後に逆行。エグジット改善では救えない
- 8-14日（score_drop）: **NOT 決定的** — 含み益があれば継続できた可能性がある
- 61日超（時間切れ）: **エグジット改善で対応可能** — 含み益のある銘柄はより早くタイト化

**改善方針:** エントリー精度向上（0-7日対策）と保有ルール精緻化（8-14日・61日超対策）を並行検証する。

### 10.2 改善施策定義

#### 施策V1: score_drop 抑制（含み益保護）（Issue #384）

**現状:** `final_score < threshold（0.58）` かつ最低保有日数（5日）を経過 → 無条件に score_drop SELL

**改善:** 含み益が N×ATR を超えている場合は score_drop を抑制し、トレーリングストップに委ねる

```python
# 現状
if final_score < threshold:
    → score_drop SELL

# 改善後
if final_score < threshold:
    if score_drop_atr_gate is not None:
        unrealized = (close - avg_price) / avg_price
        atr = _atr_20d(...)
        if atr and close - avg_price > score_drop_atr_gate * atr:
            → 抑制（トレーリングストップに委ねる）
    → score_drop SELL
```

新パラメータ: `score_drop_atr_gate: float | None = None`（例: 1.0 → 含み益 > 1×ATR で抑制）

**期待効果:** 8-14日の勝者（15-30日に移行できる可能性のある銘柄）を保持。取引コスト削減。

#### 施策V2: Stage4 トレーリングストップ（30 営業日超タイト化）（Issue #385）

**現状:**
- Stage1: peak > avg_price → ATR × 2.0
- Stage2: 保有 ≥ 6日 かつ 含み益 ≥ 1.5×ATR → ATR × 1.8
- Stage3: 保有 ≥ 21日（無条件） → ATR × 1.5

**改善:** Stage4 を追加し、長期保有かつ大きな含み益を持つ銘柄をよりタイトに管理

```
Stage4: 保有 ≥ 30 営業日 かつ 含み益率 ≥ trail_stage4_profit_gate(10%)
         → ATR × trail_stage4_mult(1.2)
```

新パラメータ: `trail_stage4_days: int = 30`、`trail_stage4_profit_gate: float = 0.10`、`trail_stage4_mult: float = 1.2`

**期待効果:** 61日超の時間切れ前にタイト化し、含み益を保護。time_exit での損失を削減。

#### 施策V3: エントリー安定フィルター（急騰・急落回避）（Issue #386）

**現状:** BUY シグナルは `final_score ≥ threshold` を満たせば発動（直近の価格動向を問わない）

**改善:** エントリー直前 3 営業日の騰落率の絶対値が N% 超の銘柄を除外

```python
# 追加フィルター
if entry_3d_max_abs_return is not None:
    ret_3d = (close_today / close_3d_ago) - 1
    if abs(ret_3d) > entry_3d_max_abs_return:
        → BUY シグナル抑制（急騰・急落銘柄は見送り）
```

新パラメータ: `entry_3d_max_abs_return: float | None = None`（例: 0.05 → ±5% 超で見送り）

**期待効果:** ストップロス（0-7日）に至る「エントリー直後の逆行」を事前に回避。

## 14. Section 55 — Group Y: TOPIX 騰落率ベースのレジーム検知強化（Issue #392）

```
     あることが根本原因。フィルターを加えると 2020・2024 の回復局面でも抑制が働いてしまう。
```

## 15. W1_08 収益集中リスク定量評価 (Issue #397)

### 15.1 背景・目的

W1_08 は IS 9年間（2017–2025）で CAGR 14.4%・Sharpe 0.674 を達成しているが、
収益の大半が 2018（+49.4%）・2024（+52.6%）の 2 年に集中している。
本番運用後に「大相場の年」が数年来なかった場合のリスクを定量化する。

分析スクリプト: `backtest/backtest_improvement_plan/analyze_phase2_concentration_risk.py`  
成果物: `artifacts/backtest/backtest_phase2_concentration_risk/`

### 15.3 2018・2024 除外シミュレーション（7年）

| 指標 | W1_08 全期間 | 2018・2024 除外（7年）| 差分 |
| ---- | -----------: | ---------------------: | ---: |
| CAGR | **14.4%** | **+4.6%** | −9.8pt |
| MaxDD（年末ベース）| 6.3% | 6.3% | — |
| 総収益率 | +213.1% | +37.3% | — |
| プラス年 | 8/9 | 6/7 | — |

**解釈:** 大相場 2 年を除くと年率 +4.6% に低下。「急落→回復モメンタム」の大相場が
来なければ数年にわたって資産がほぼ横ばいになるシナリオは現実的。

> ※ **CAGR の差異について**: スクリプトが年次リターン（丸め済み）を複利合成した計算値は
> 約 13.5% であり、IS 参照値 14.4% と約 0.9pt の乖離がある。IS 参照値は日次データを
> 用いたバックテストエンジンの計算値（月次複利の精度）であり、より正確。本表は IS 参照値を採用。
>
> ※ **MaxDD の差異について**: 18.4%（IS 参照値）は日次ベースのドローダウン。
> 上表は年末時価ベースの MaxDD（6.3%）のため、年内高値からの落ち込みは含まない。

### 15.4 最悪連続マイナス年シミュレーション

| 連続年数 | 年次仮定 | 資本毀損 | 1000 万円 → |
| -------: | -------: | -------: | ----------: |

| 2 年 | −6.3% | −12.2% | 878 万円 |
| **3 年** | **−6.3%** | **−17.7%** | **823 万円** |

**3 年連続で実績最悪リターンを繰り返しても資本毀損は −17.7%（MaxDD 許容 25% 以内）。**  
ただし資産が 82% まで低下する期間中の精神的耐性と追加投資停止判断が現実的な課題。

実績マイナス年: **2022 年の 1 年のみ**（2023 は +0.4% でギリギリプラス）

### 15.7 本番投入リスク開示

#### 想定シナリオ

| シナリオ | 年率リターン目安 | 最大資産毀損 |
| -------- | -------------- | ----------- |
| 大相場あり（2018/2024 相当） | +40〜55% | 〜20% |
| 通常相場（2017/2019〜2021/2025 相当） | +5〜10% | 〜10% |
| 大相場なし 7 年 | **+4.6%/年** | **6%（年末ベース）** |
| 3 年連続最悪ケース | −6.3%/年 | **−17.7%** |

#### 採用判断コメント

```
■ 収益集中リスク
  2018・2024 の 2 年で総利益の 68.9% を生成。
  本番運用後に同様の大相場が来なければ、数年間 CAGR が +4〜5% 程度に止まる可能性が高い。

■ MaxDD 許容範囲内
  3 年連続最悪ケースでも資本毀損 −17.7%（許容基準 25% 以内）。
  戦略の損失許容度は妥当。

■ dd_stop 発動リスク
  2024・2025 は年内 DD が 12% を超えた（2/9 年 = 22%）。
  dd_stop 発動後に相場回復した場合の機会損失リスクあり。
  閾値を 18〜20% に緩和することも検討余地あり。

■ 本番運用における評価軸
  - 短期（1〜2年）: 年率 5〜15% の範囲で大相場を待つ「待機モード」として認識
  - 中長期（3〜5年）: 大相場を 1〜2 回経験すれば CAGR 10%+ が期待できる
  - MaxDD 警戒ライン: 年内 18% 超（全期間 MaxDD 相当）で戦略見直し検討
```
